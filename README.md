# 🥐 Umi Fika Bakery & Pastry — Website UMKM

Website modern, interaktif, dan premium untuk UMKM **Umi Fika Bakery & Pastry** — *"Artisanal Bakes For Wholesome Mornings"*.

## ✨ Fitur Utama

- 🥖 **Desain Editorial Premium**: Tipografi modern dengan Plus Jakarta Sans & Instrument Serif Italic, micro-animations, dan layout estetik.
- 🥐 **Katalog Produk & Detail Modal**: Menampilkan pilihan pastry, sourdough, croissant, informasi bahan, dan alergen.
- 🛒 **Keranjang Belanja & Checkout WhatsApp**: Pengunjung dapat memilih produk dan langsung checkout ke WhatsApp secara otomatis dengan format pesanan rapi.
- 📦 **Kalkulator Paket Acara**: Rekomendasi otomatis paket sarapan, meeting kantor, keluarga, hingga hampers.
- 📱 **100% Responsif**: Tampilan optimal di desktop, tablet, dan smartphone.

## 🚀 Tech Stack

- **React 18** + **Vite**
- **Tailwind CSS**
- **Framer Motion** & **Lucide React**
- **Standalone Version**: Juga tersedia versi standalone HTML + Vanilla JS di folder `umi-fika-bakery-html-standalone/`.

## 🛠️ Cara Menjalankan

1. Clone repositori:
   ```bash
   git clone https://github.com/Nazrilajeha/websiteumkm.git
   cd websiteumkm
   ```

2. Install dependensi:
   ```bash
   npm install
   ```

3. Jalankan server lokal:
   ```bash
   npm run dev
   ```

4. Build untuk produksi:
   ```bash
   npm run build
   ```
